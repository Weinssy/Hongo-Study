Orang & Kata Ganti

Daftar lengkap kata ganti orang (pronomina), sebutan usia/sosial, serta kewarganegaraan dalam bahasa Jepang.

1. Kata Ganti Orang (人称代名詞)

Kata Ganti Utama & Sopan

  • Saya (Standar)  —  watashi (私 / わたし)
  • Saya (Sangat Formal / Pidato)  —  watakushi (わたくし)
  • Aku (Laki-laki / Netral)  —  boku (僕 / ぼく)
  • Gue / Aku (Pria Akrab)  —  ore (俺 / おれ)
  • Aku (Perempuan Akrab)  —  atashi (あたし)
  • Diri Sendiri  —  jibun (自分 / じぶん)
  • Anda / Kamu  —  anata (あなた)
  • Kamu (Akrab / Sebaya)  —  kimi (君 / きみ)
  • Dia (Laki-laki)  —  kare (彼 / かれ)
  • Dia (Perempuan)  —  kanojo (彼女 / かのじょ)
  • Orang ini (Biasa)  —  kono hito (この人 / このひと)
  • Orang itu (Biasa)  —  sono hito / ano hito (その人 / あの人)
  • Orang ini (Hormat)  —  kono kata (この方 / このかた)
  • Orang itu (Hormat)  —  sono kata / ano kata (その方 / あの方)

Bentuk Jamak & Kolektif

  • Kita / Kami  —  watashitachi (私たち / わたしたち)
  • Kita / Kami (Laki-laki)  —  bokutachi / bokura (僕たち / 僕ら)
  • Kita / Kami (Pria Akrab)  —  oretachi / orera (俺たち / 俺ら)
  • Kami / Pihak Kami (Formal)  —  wareware (我々 / われわれ)
  • Kalian / Anda Sekalian  —  anatatachi (あなたたち)
  • Anda Sekalian (Hormat)  —  anatagata (あなた方 / あなたがた)
  • Kalian (Sebaya)  —  kimitachi / kimira (君たち / 君ら)
  • Mereka (Laki-laki / Campuran)  —  karera (彼ら / かれら)
  • Mereka (Perempuan)  —  kanojora (彼女ら / かのじょら)
  • Semuanya (Kasual)  —  min'na (みんな)
  • Hadirin / Semuanya (Sopan)  —  minasan (皆さん / みなさん)
  • Seluruh Hadirin (Sangat Hormat)  —  minasama (皆様 / みなさま)
  • Seluruh Anggota / Semua Orang  —  zen'in (全員 / ぜんいん)
  • Orang-orang ini (Hormat)  —  kono katagata (この方々 / このかたがた)

2. Kosakata Orang & Kelompok Usia

Gender & Hubungan Sosial

  • Orang  —  hito (人 / ひと)
  • Orang-orang  —  hitobito (人々 / ひとびと)
  • Manusia  —  ningen (人間 / にんげん)
  • Pria / Laki-laki  —  dansee / otoko (男性 / 男)
  • Wanita / Perempuan  —  josee / onna (女性 / 女)
  • Anak Laki-laki  —  otokonoko (男の子 / おとこのこ)
  • Anak Perempuan  —  onnanoko (女の子 / おんなのこ)
  • Teman / Sahabat  —  tomodachi (友達 / ともだち)
  • Pacar / Kekasih  —  koibito (恋人 / こいびと)
  • Lawan Bicara / Rekan  —  aite (相手 / あいて)
  • Orang Terkenal  —  yuumeejin (有名人 / ゆうめいじん)
  • Orang Populer  —  ninkimono (人気者 / にんきもの)

Tahapan Usia & Status

  • Bayi  —  akachan (赤ちゃん / あかちゃん)
  • Balita  —  yooji (幼児 / ようじ)
  • Anak-anak  —  kodomo (子供 / こども)
  • Anak Kembar  —  futago (双子 / ふたご)
  • Anak Muda / Pemuda  —  wakamono (若者 / わかもの)
  • Remaja  —  seenen (青年 / せいねん)
  • Orang Dewasa  —  otona (大人 / おとな)
  • Paruh Baya  —  chuunen (中年 / ちゅうねん)
  • Lansia (Sopan & Ramah)  —  otoshiyori (お年寄り / おとしより)
  • Warga Lanjut Usia (Formal)  —  kooreesha / roojin (高齢者 / 老人)
  • Lajang (Single)  —  dokushin (独身 / どくしん)
  • Sudah Menikah  —  kikon (既婚 / きこん)
  • Belum Menikah  —  mikon (未婚 / みこん)
  • Anak Tersesat  —  maigo (迷子 / まいご)

3. Orang Asing & Kewarganegaraan (～人)

Istilah Umum & Asia

  • Orang Asing  —  gaikokujin (外国人 / がいこくじん)
  • Pelajar Asing  —  ryuugakusee (留学生 / りゅうがくせい)
  • Orang Jepang  —  nihonjin (日本人 / にほんじん)
  • Orang Indonesia  —  indoneshiajin (インドネシア人)
  • Orang Malaysia  —  mareeshiajin (マレーシア人)
  • Orang Singapura  —  shingapoorujin (シンガポール人)
  • Orang Tiongkok  —  chuugokujin (中国人 / ちゅうごくじん)
  • Orang Korea Selatan  —  kankokujin (韓国人 / かんこくじん)
  • Orang Asia  —  ajiajin (アジア人)
  • Orang Jawa  —  jawajin (ジャワ人)
  • Orang Sunda  —  sundajin (スンダ人)
  • Orang Bali  —  barijin (バリ人)

Negara Barat & Istilah Lainnya

  • Orang Barat  —  seeyoojin / oobeejin (西洋人 / 欧米人)
  • Orang Amerika  —  amerikajin (アメリカ人)
  • Orang Inggris  —  igirisujin (イギリス人)
  • Orang Jerman  —  doitsujin (ドイツ人)
  • Orang Prancis  —  furansujin (フランス人)
  • Orang Belanda  —  orandajin (オランダ人)
  • Orang Spanyol  —  supeinjin (スペイン人)
  • Orang Kulit Putih  —  hakujin (白人 / はくじん)
  • Orang Kulit Hitam  —  kokujin (黒人 / こくじん)
  • Alien / Makhluk Luar Angkasa  —  uchuujin (宇宙人 / うちゅうじん)
