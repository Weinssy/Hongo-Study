Kosakata Dasar

Pekerjaan & Profesi

Daftar lengkap kosakata profesi, karier, status pekerjaan, dan dunia kerja dalam bahasa Jepang.

1. Kategori & Status Pekerjaan

  • Pekerjaan  —  shigoto (仕事 / しごと)
  • Profesi  —  shokugyoo (職業 / しょくぎょう)
  • Karyawan / Pegawai  —  shain (社員 / しゃいん)
  • Karyawan Tetap  —  see-shain (正社員 / せいしゃいん)
  • Karyawan Kontrak  —  keeyaku-shain (契約社員 / けいやくしゃいん)
  • Karyawan Alih Daya (Outsource)  —  haken-shain (派遣社員 / はけんしゃいん)
  • Pekerja Lepas (Freelance)  —  furiiransu (フリーランス)
  • Pekerja Paruh Waktu (Part-time)  —  arubaito (アルバイト)
  • Staf  —  sutaffu (スタッフ)
  • Wirausahawan / Pendiri Usaha  —  kigyooka (起業家 / きぎょうか)
  • Pemilik Usaha Mandiri (Self-employed)  —  jieegyoo (自営業 / じえいぎょう)
  • Profesional  —  puro (プロ)
  • Amatir  —  amachua (アマチュア)
  • Bidang Keahlian / Spesialisasi  —  senmon (専門 / せんもん)
  • Petugas / Penanggung Jawab  —  kakari (係 / かかり)
  • Ibu Rumah Tangga  —  shufu (主婦 / しゅふ)
  • Belum Bekerja / Pengangguran  —  mushoku (無職 / むしょく)

  • Fotografer  —  shashin-ka / kameraman (写真家 / カメラマン)

  • Aktor / Aktris  —  haiyuu (俳優 / はいゆう)
  • Aktor (Pria)  —  danyuu (男優 / だんゆう)
  • Aktris (Wanita)  —  joyuu (女優 / じょゆう)
  • Pengisi Suara (Voice Actor)  —  seeyuu (声優 / せいゆう)
  • Penyanyi  —  kashu (歌手 / かしゅ)
  • Idola (Idol)  —  aidoru (アイドル)
  • Selebriti / Penampil TV  —  tarento / geenoo-jin (タレント / 芸能人)
  • Model  —  moderu (モデル)

  • YouTuber  —  yuuchuubaa (ユーチューバー)
  • Influencer  —  infuruensaa (インフルエンサー)
